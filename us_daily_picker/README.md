# 美股每日自动选票

该目录把已经完成审计的美股自由流通活跃度策略部署为 GitHub Actions 定时任务。

## 定时安排（全部按 America/New_York）

- **主运行：交易日 18:15 ET 左右**，在常规收盘后的夜盘阶段生成下一交易日名单。
- **盘前兜底：下一交易日 08:45 ET 左右**。如果夜盘阶段已成功生成，则自动跳过；如果夜盘数据尚未更新，则盘前补跑。
- Python 程序使用 `America/New_York` 时区和 XNYS 交易日历，因此自动适配夏令时、冬令时、周末、交易所假日和提前收盘日。

GitHub cron 只能使用 UTC，所以工作流同时安排夏令时和冬令时对应的 UTC 时刻；程序会在美东时间窗口外自动退出，并通过日期文件保证幂等。

## 每日入场信号

1. 证券必须在信号日处于历史上市区间。
2. 自由流通市值只使用信号日前已公开的 SEC `dei:EntityPublicFloat`。
3. 原始收盘价不低于 1 美元。
4. 当日成交额不低于 100 万美元。
5. 推算自由流通市值不低于 2,000 万美元。
6. 按 `成交金额 / 自由流通市值` 对覆盖股票池排序。
7. 先取全市场前三，再保留信号日收盘跌幅不高于 -8% 的股票。
8. 下一正常交易日常规时段开盘等权介入。

## 统一卖出计划

- 实际成交价上方 +10% 止盈；
- 实际成交价下方 -15% 止损；
- 未触发止盈或止损时，最迟于 D+3 常规收盘退出；
- 同一根日线同时触及止盈和止损时，按止损先发生；
- 上一批持仓未全部退出时，新信号仅作观察，不重复满仓开新批次。

## 输出

成功运行后会：

- 写入 `daily_picks/YYYY-MM-DD/picks.md`；
- 写入完整的 `top3.csv`、`selected.csv` 和 `picks.json`；
- 更新 `daily_picks/latest.md` 与 `daily_picks/latest.json`；
- 创建或更新一个 GitHub Issue，标题中包含信号日、计划入场日和代码；
- 即使无交易信号，也会发布 `NO TRADE` 通知；
- 保留 14 天 GitHub Actions 审计附件。

## 手动运行

在 Actions 页面选择 `US daily stock picker`，可填写历史信号日并强制重跑。历史日期必须是 XNYS 正常或提前收盘交易日。

## 边界

这是自动生成候选名单的研究系统，不连接券商，也不自动下单。SEC public float 是周期性官方披露而非每日股东名册；日线无法模拟竞价排队、停牌、买卖价差、部分成交和市场冲击。
